# Wiki SnkMC — contenu

Ce dépôt public ne contient que la documentation, les médias, la configuration éditoriale et les relais GitHub Actions. Le moteur est dans `LuluxClient/wiki-engine`.

- Toute correction de contenu passe par pull request et relecture.
- Les pages sont du Markdown sans code exécutable.
- Préserver les versions française et anglaise, leurs `pageId` et les URLs existantes.
- Respecter les sources, les crédits et les limites indiquées dans `SOURCES.md` et `LICENSES.md`.
- Ne pas ajouter de secrets, scripts, dépendances npm ni artefacts compilés.
- Les workflows sont une infrastructure réservée aux mainteneurs.
