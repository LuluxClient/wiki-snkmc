The **Orders** plugin organises objectives that request items or actions. An order is a useful way to turn farm resources into targeted progression.

## Method

1. Read the requested item and quantity.
2. Check whether it must be delivered, sold or simply owned.
3. Compare the reward with the item’s value.
4. Keep a screenshot if the wording is unclear.

Orders may change with seasons or events. This page documents the general flow rather than a fixed list of requests.
