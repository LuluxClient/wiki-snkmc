The player-shop system uses **/playershops** and the **/ps** alias. The current configuration requires sneaking to interact with a shop and displays shop information through a hologram.

## Available actions

The help message lists deleting your shop, managing shop staff, changing mode, changing price, viewing transactions and searching shops.

## Safety

- Check the owner, item and displayed stock.
- Confirm the price before every purchase.
- Never put a password or private data in a shop name.
- Report a shop that cannot be used instead of trying to bypass its state.
