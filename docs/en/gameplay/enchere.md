The server exposes an auction system with **AuctionMaster** and **AuctionPulse**. The exact menu, fees and listing duration must be checked on the active version.

## Before listing

- Compare the price with player shops.
- Check quantity and item state.
- Read any fees and listing duration.
- Remove expired listings if the menu provides that option.

## Before buying

Check name, rarity, quantity, seller and unit price. A screenshot of the search result helps resolve a dispute.
