Cosmetics change appearance without replacing combat equipment. The reference plugin contains hats and other visual items grouped by rarity.

## Good habits

- Preview an item before confirming it.
- Check whether it is permanent, consumable or event-only.
- Do not sell a collection cosmetic before confirming that it can be recovered.
