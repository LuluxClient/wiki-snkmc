Scrolls form a distinct progression item family. Depending on their type, they may come from rewards, content commands, events or adventure activities.

Before consuming a scroll:

1. check the target player;
2. read the duration and bonus;
3. see whether the bonus stacks or replaces an existing effect;
4. use it when you can benefit from it.

Exact values should be documented with a menu screenshot and the server version so an old balance is not frozen into the wiki.
