The rank system connects progression to player-level, job-level or titan-level goals. The default rank is **Recruit**.

## Ranks found in the reference configuration

Recruit, Aspirant, Cadet, Soldier, Scout, Garrison, Veteran, Lieutenant, Captain, Major, Officer, Chief, Commander, Hero, Legend, Supreme, Marshal and Elite.

The list and conditions may receive new milestones. Use the rank menu to see the exact missing objective instead of assuming that a single level is enough.

## Advice

- Raise jobs alongside your player level.
- Keep ascension resources instead of selling them immediately.
- If an objective looks stuck, use the rank detail panel or contact staff.
