Rewards do not come from one single system. The server distinguishes jobs, votes, events, quests, the pass and adventure areas.

## Before claiming

- Leave room in your inventory.
- Check the source of the reward.
- Read the duration of any boost.
- Capture the reward if it differs from the description.

The reference inventory includes **Rewards**, **RewardZone**, **Voty**, **EventCore** and **BusterCallEvent**. Active event content should always be announced separately.
