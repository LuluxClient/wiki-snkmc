The camp system uses **/camp**, with **/island** and **/is** aliases. Some menus also display the historical name **base camp**.

## Observed starting values

- PvP is disabled by default.
- The island starts closed.
- The default border is 50 blocks.
- The default member limit is 3.
- An island can publish 1 warp by default.
- The configured disband limit is 3.

Limits may be upgraded or changed by staff. Before disbanding a camp, check members, chests and bank: disbanding has a major impact.
