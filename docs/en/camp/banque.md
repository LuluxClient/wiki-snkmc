The **Treasure** menu uses **/tresor** and the aliases **/treasure**, **/tesoro** and **/schatz**. Island level is based on value deposited in the treasure.

## Seals found in the configuration

| Seal | Value |
| --- | ---: |
| Bronze | 100 |
| Silver | 200 |
| Gold | 600 |
| Ruby | 1,000 |
| Royal | 3,000 |

The configured maximum value is 10,000,000. The menu provides a reset action: read its warning and confirmation carefully before using it.
