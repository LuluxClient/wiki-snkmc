Warps share a camp access point. The configuration provides promotion prices and durations by tier; the observed starting value is 1,000 for 86,400 seconds.

Subareas allow different permissions for part of an island. The menu documents **/camp subarea create name** for creating a subarea.

## Before publishing

- Place a warp in a safe area.
- Check which role can use the subarea.
- Do not publish access to a private bank or storage.
- Remove a warp that is no longer useful.
