The **DevilishFruit** system provides fruit consumption, equipment and ascension menus. The reference configuration contains a common **Bandit Fruit** with an ability and a level-20 ascension.

:::caution[Status to confirm]
The active configuration indicates that fruits are disabled and the internal fruit command is disabled. This page describes the planned system, not guaranteed public availability.
:::

## Ascension

Costs vary by rarity and level. They may combine money, boss, dungeon and farm materials. A successful ascension advances the fruit; check the menu after a failure before trying again.
