The Haki system is configured with **Haki King** milestones numbered 1 to 10. The reference settings add 2 units per increment and use a 30-second recovery delay.

## Use

Activate Haki when its bonus is useful, then watch the availability message before using it again. Messages indicate when Haki is activated and when it can be reused.

Power values and access conditions may depend on progression. Confirm them using the active menu panel.
