The menus mention three fortresses:

- Forest Fort;
- Plains Fort;
- High Forest Fort.

Dungeon materials are used by weapon and fruit ascensions. Prepare a group if a fortress requires coordinated combat and check the entry cost before using a ticket or resource.

Duration, waves, rewards and access requirements should be captured in game for each version of a fortress.
