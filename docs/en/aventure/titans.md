The **DevilTitan** system provides eight transformations. Every titan has a configured maximum level of 50, along with its own skills, stats and ascension milestones.

| Titan | Rarity |
| --- | --- |
| Jaw Titan | Rare |
| Cart Titan | Epic |
| War Hammer Titan | Epic |
| Armored Titan | Legendary |
| Female Titan | Legendary |
| Attack Titan | Mythic |
| Beast Titan | Mythic |
| Colossal Titan | Mythic |

## Transformation

The system distinguishes human-to-titan transformation, the return to human form, sprint and walking. Energy is consumed by skills. The configured delay is 300 seconds by default and 150 seconds with the VIP permission; admin permissions ignore it.

The observed ascension milestones start at levels 5, 15, 25 and 40 and request titan samples, medals, plant resources and money.
