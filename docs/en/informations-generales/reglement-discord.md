## In channels

- Read each channel’s description and topic.
- Use help channels for questions and report channels for problems.
- Avoid spam, excessive pings and off-topic messages.
- Never publish personal information or content that could endanger someone.

## Support and reports

A useful report includes the name involved, the date, the context and unmodified evidence. Do not publish tokens, private addresses or screenshots containing sensitive information.

## Community content

Guides, videos and screenshots are welcome when they follow the server rules and respect their authors’ rights. Ask permission before reusing an image or text.

:::note
Discord rules can change independently from the wiki. The rules displayed in the official Discord server remain authoritative.
:::
