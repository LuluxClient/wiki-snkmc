## About this wiki

This wiki is organised as a game guide: each page explains a mechanic, gives its entry point and provides progression advice. French and English pages share the same stable identifier so updates can be tracked in both languages.

The initial inventory was prepared from the SnkMC development environment. Technical-only plugins, generated files and sensitive data are not exposed in the wiki. Details that depend on a menu or a dynamic value are marked for verification.

## Sources of truth

1. Rules and announcements published by staff.
2. Behaviour observed in game on the active version.
3. Server menus and messages.
4. This documentation, updated through pull requests.

## Reporting an incorrect detail

Use the contribution button at the bottom of an article. Include the context: command used, menu opened, expected result and observed result. A screenshot without personal information makes verification easier.
