## Camp and treasure

| Command | Use |
| --- | --- |
| /camp | Open the camp system |
| /island, /is | Camp aliases |
| /camp subarea create name | Create a subarea |
| /tresor | Open island treasure |
| /treasure, /tesoro, /schatz | Treasure aliases |

## Jobs and ranks

| Command | Use |
| --- | --- |
| /jobs claim | Claim pending job rewards |
| /ranker inspect player objective | Inspect a rank objective |
| /ranker setrank player rank | Set a rank, staff-only |
| /ranker complete player objective | Complete an objective, staff-only |
| /ranker increment player objective | Increment an objective, staff-only |

Staff commands are listed to explain messages, not to suggest bypassing permissions.
