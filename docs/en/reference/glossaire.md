| Term | Meaning |
| --- | --- |
| Ascension | Moving to a milestone by spending resources |
| Boss | Creature or opponent with specific loot |
| Dungeon | Separate activity with its own rewards |
| Farm | Produced or harvested resource |
| Haki | Power system with milestones and recovery |
| Warp | Shared teleport point |
| Seal | Camp treasure value unit |
| Boost | Effect that adds to or replaces a bonus |
| Rarity | Collection tier: common, rare, epic, legendary or mythic |
