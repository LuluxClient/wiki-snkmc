## Recommended structure

1. Start with one sentence explaining the system.
2. Add prerequisites and the command or menu.
3. Give a short procedure.
4. Use a table for repeated values.
5. End with known limits and the verification date.

## Images and rights

Screenshots must describe what they show through useful alternative text. Use only images whose authors allow sharing and keep their credits. Never include a secret, token, private address or personal data.

## French version

When an English page changes, update the matching French page under the root documentation. Keep the same filename and page identifier so the language switcher associates both versions.
