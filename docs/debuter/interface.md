SnkMC utilise plusieurs composants pour afficher la progression : **EpicHUD**, **BoardMaster**, **Hologrammer**, **SquidMenus** et **SquidCore**. Selon la zone et votre progression, les informations peuvent apparaître dans le HUD, un scoreboard, un hologramme ou un menu interactif.

## Lire une fiche

- Le niveau et la barre d’expérience indiquent votre progression.
- La rareté distingue souvent les objets, familiers, montures et titans.
- Les lignes de coût listent les ressources nécessaires.
- Une permission ou une condition non remplie doit être distinguée d’un objet manquant.
