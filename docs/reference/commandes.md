## Camp et trésor

| Commande | Usage |
| --- | --- |
| /camp | Ouvrir le système de camp |
| /island, /is | Alias du camp |
| /camp subarea create nom | Créer une sous-zone |
| /tresor | Ouvrir le trésor de l’île |
| /treasure, /tesoro, /schatz | Alias du trésor |

## Métiers et rangs

| Commande | Usage |
| --- | --- |
| /jobs claim | Récupérer des récompenses de métier en attente |
| /ranker inspect joueur objectif | Inspecter un objectif de rang |
| /ranker setrank joueur rang | Définir un rang, réservé au staff |
| /ranker complete joueur objectif | Valider un objectif, réservé au staff |
| /ranker increment joueur objectif | Incrémenter un objectif, réservé au staff |

Les commandes staff sont listées ici pour expliquer certains messages, pas pour suggérer un contournement de permission.
