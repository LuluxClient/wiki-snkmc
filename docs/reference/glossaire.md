| Terme | Signification |
| --- | --- |
| Ascension | Passage d’un palier contre des ressources |
| Boss | Créature ou adversaire donnant un butin spécifique |
| Donjon | Activité séparée avec ses propres récompenses |
| Farm | Ressource produite ou récoltée |
| Haki | Système de pouvoir avec paliers et récupération |
| Warp | Point de téléportation partagé |
| Sceau | Unité de valeur du trésor de camp |
| Boost | Effet qui additionne ou remplace un bonus |
| Rareté | Niveau de collection : commune, rare, épique, légendaire ou mythique |
