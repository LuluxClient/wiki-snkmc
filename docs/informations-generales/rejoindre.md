## Avant la première connexion

- Utilisez une installation Minecraft compatible avec la version annoncée par le staff.
- Vérifiez que votre compte possède bien l’accès multijoueur.
- Rejoignez les canaux officiels pour connaître l’adresse actuelle, les maintenances et les prérequis.
- Gardez votre pseudonyme et votre identifiant de compte cohérents entre le jeu et les services liés.

L’adresse de connexion, la version exacte et les éventuels mods requis doivent être ajoutés ici après validation par l’équipe SnkMC. Ils ne sont volontairement pas devinés dans cette première édition.

## Premier chargement

1. Entrez dans le serveur et lisez les messages d’accueil.
2. Ouvrez le menu principal et repérez les accès vers le camp, l’aventure, les métiers et les récompenses.
3. Suivez le tutoriel avant de dépenser vos premières ressources.
4. Si un menu n’est pas disponible, reconnectez-vous puis vérifiez les annonces de maintenance.
