## À propos de ce wiki

Ce wiki est structuré comme un guide de jeu : les pages expliquent une mécanique, indiquent ses points d’entrée et donnent des conseils de progression. Les pages bilingues partagent le même identifiant stable afin que les corrections puissent être suivies en français et en anglais.

L’inventaire initial a été préparé depuis l’environnement de développement SnkMC. Les plugins purement techniques, les fichiers générés et les données sensibles ne sont pas exposés dans le wiki. Les descriptions qui dépendent d’un menu ou d’une valeur dynamique portent une note de vérification.

## Les sources de vérité

1. Les annonces et règles publiées par le staff.
2. Le comportement constaté en jeu sur la version active.
3. Les menus et messages du serveur.
4. Cette documentation, mise à jour par pull request.

## Signaler une information incorrecte

Utilisez le bouton de contribution en bas de chaque page. Ajoutez le contexte : commande utilisée, menu ouvert, résultat attendu et résultat observé. Une capture sans information personnelle accélère la vérification.
