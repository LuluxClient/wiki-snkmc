Le camp est votre espace de groupe : il regroupe les membres, les permissions, la banque, les générateurs, les améliorations, les warps et les sous-zones.

## Les menus principaux

- **Camp** : créer, rejoindre et gérer l’île.
- **Trésor** : consulter la valeur et les sceaux du camp.
- **Membres** : inviter, retirer et attribuer un rôle.
- **Paramètres** : activer ou désactiver les règles de l’île.
- **Générateurs** : consulter la production et les améliorations.
- **Warps** : publier des points de téléportation.
