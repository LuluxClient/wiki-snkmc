La configuration de départ repère les probabilités suivantes :

| Bloc | Taux de départ |
| --- | ---: |
| Pierres et variantes de pierre | 70 % de cobblestone, 20 % de stone, 1 % d’andésite, 1 % de granite, 1 % de diorite |
| Minerais | 5 % de charbon, 2 % de fer |

Les pourcentages sont liés à la configuration du générateur de départ. Les améliorations, le prestige ou un autre générateur peuvent appliquer un tableau différent.
