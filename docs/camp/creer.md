Le système de camp utilise la commande de base **/camp**, avec les alias **/island** et **/is**. Certains menus affichent aussi le nom historique **base camp**.

## Valeurs de départ repérées

- Le mode JcJ est désactivé par défaut.
- L’île démarre fermée.
- La bordure par défaut est de 50 blocs.
- La limite par défaut est de 3 membres.
- Une île peut publier 1 warp par défaut.
- La limite de dissolution configurée est de 3.

Les limites peuvent être améliorées ou modifiées par le staff. Avant de dissoudre un camp, vérifiez les membres, les coffres et la banque : une dissolution est une action à fort impact.
