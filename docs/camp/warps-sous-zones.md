Les warps permettent de partager un point d’accès du camp. La configuration prévoit un prix et une durée de promotion des warps par paliers ; la valeur de départ observée est de 1 000 pour 86 400 secondes.

Les sous-zones permettent de donner des permissions différentes à une partie de l’île. Le menu documente la commande **/camp subarea create nom** pour créer une sous-zone.

## Avant de publier

- Placez le warp dans une zone sûre.
- Vérifiez le rôle requis pour utiliser la sous-zone.
- Évitez de publier l’accès à une banque ou à un stockage privé.
- Retirez un warp devenu obsolète.
