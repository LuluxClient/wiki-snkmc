## Rôles configurés

La configuration repère les rôles **Invité**, **Coop**, **Membre**, **Modérateur**, **Administrateur** et **Chef**. Le rôle Coop est décrit comme un membre temporaire.

Les permissions peuvent couvrir les animaux, les monstres, les coffres, la banque, le placement, la destruction, l’interaction et le vol. Donnez le rôle le plus faible qui suffit à la tâche.

## Bonnes pratiques

- N’invitez pas un joueur inconnu avec un rôle élevé.
- Retirez les accès temporaires après une construction.
- Vérifiez la liste des membres avant une vente ou une dissolution.
- Testez une permission dans une zone sans objets précieux.
