Le menu **Trésor** utilise la commande **/tresor** et ses alias **/treasure**, **/tesoro** et **/schatz**. Le niveau de l’île s’appuie sur une valeur déposée dans le trésor.

## Sceaux repérés

| Sceau | Valeur |
| --- | ---: |
| Bronze | 100 |
| Argent | 200 |
| Or | 600 |
| Rubis | 1 000 |
| Royal | 3 000 |

La valeur maximale configurée est de 10 000 000. Le menu prévoit un reset : vérifiez l’avertissement et la confirmation avant de l’utiliser.
