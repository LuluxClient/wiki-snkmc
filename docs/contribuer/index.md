Le wiki évolue par pull request. Une contribution utile est petite, vérifiable et accompagnée de son contexte.

Pour corriger une ligne, cliquez sur **Modifier sur GitHub** en bas de la page. Pour écrire avec un aperçu et ajouter une image, ouvrez l’[éditeur visuel local](/editor/) après avoir cloné votre fork avec GitHub Desktop. Enregistrez dans votre dossier, puis faites **Commit**, **Push origin** et **Create Pull Request** dans GitHub Desktop. Le staff relit avant publication ; aucune commande ou connexion Cloudflare n’est nécessaire.

## Une bonne proposition contient

- le nom de la page ;
- l’information à corriger ;
- la commande ou le menu utilisé ;
- la date et la version constatées ;
- une capture sans donnée privée ;
- la langue concernée, français, anglais ou les deux.

Les sources issues de fichiers de configuration servent à préparer le contenu, mais ne remplacent pas une validation en jeu lorsqu’il s’agit d’un prix, d’un butin ou d’une règle active.
