La pêche et l’agriculture alimentent plusieurs boucles de progression : métiers, récompenses, ascensions et ordres. Les zones d’aventure peuvent proposer des ressources spécifiques, plus intéressantes que les ressources de départ.

## Conseils de production

- Gardez un stock de matériaux communs pour les premières ascensions.
- Triez les ressources par zone pour retrouver la provenance d’un objet.
- Vérifiez si une quête demande une qualité, une quantité ou une zone particulière.
- Évitez de vendre une ressource rare avant d’avoir consulté les coûts d’ascension.

Les plugins **Farmers** et **MoreFish** sont présents dans l’environnement de référence. Les tables de butin doivent être ajoutées avec une capture ou une source validée pour rester fiables.
