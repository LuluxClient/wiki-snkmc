Le système de boutiques joueurs utilise la commande principale **/playershops** et l’alias **/ps**. La configuration actuelle demande de s’accroupir pour interagir avec une boutique et affiche les informations avec un hologramme.

## Actions prévues

La commande d’aide référence les actions suivantes : supprimer sa boutique, gérer les responsables, changer le mode, modifier le prix, consulter les transactions et rechercher une boutique.

## Sécurité

- Vérifiez le propriétaire, l’objet et le stock affiché.
- Contrôlez le prix avant chaque achat.
- Ne placez jamais un mot de passe ou une donnée privée dans un nom de boutique.
- Signalez une boutique impossible à utiliser plutôt que de tenter de contourner son état.
