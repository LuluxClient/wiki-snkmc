Le plugin **Orders** organise des objectifs qui demandent des objets ou des actions. Un ordre est une bonne manière de transformer les ressources de farm en progression ciblée.

## Méthode

1. Lisez l’objet demandé et la quantité.
2. Vérifiez s’il faut le livrer, le vendre ou simplement le posséder.
3. Comparez la récompense avec la valeur de l’objet.
4. Conservez une capture si le texte de l’ordre semble ambigu.

Les ordres peuvent évoluer avec les saisons ou les événements. Cette page documente le fonctionnement général, pas une liste figée de demandes.
