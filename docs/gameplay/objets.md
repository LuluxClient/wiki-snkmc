Le catalogue SnkMC est réparti entre les objets du gameplay, les modèles d’objets et les objets créés pour l’aventure. Les familles visibles dans l’inventaire comprennent notamment les armes, les matériaux de titan, les médailles, les graines, les ressources de farm et les récompenses de zone.

## Comprendre une fiche d’objet

- Le nom et l’icône identifient l’objet.
- La rareté indique son niveau de collection.
- Le lore peut préciser l’usage, le niveau ou la source.
- Un objet de boss, de donjon ou de farm est souvent destiné à une ascension.

Les noms internes ne sont pas toujours les noms à communiquer aux joueurs. Pour une contribution, utilisez le nom affiché en jeu et ajoutez le chemin du menu plutôt qu’un identifiant technique.
