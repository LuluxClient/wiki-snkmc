# Wiki SnkMC — contenu communautaire

Ce dépôt public contient les pages du wiki SnkMC. Le site se consulte à
<https://luluxclient.github.io/wiki-snkmc/> et l’éditeur local à
<https://luluxclient.github.io/wiki-snkmc/editor/>.

- `docs/` : pages françaises ; les traductions correspondantes sont sous `docs/en/`.
- `media/` : images autorisées et créditées.
- `wiki.json` et `hierarchy.json` : titre, rubriques et navigation, sans code exécutable.
- `SOURCES.md` et `LICENSES.md` : provenance, limites de vérification et droits.

Les pages et images passent par pull request. Les règles annoncées par le staff et le comportement du serveur actif priment sur la documentation. Le moteur Astro et l’éditeur vivent dans le dépôt privé `LuluxClient/wiki-engine` ; ils ne sont pas copiés ici. Aucun service de connexion tiers n’est déployé.

Pour une correction rapide, utilisez « Modifier sur GitHub » au bas d’une page : connectez-vous avec GitHub, corrigez le texte dans le navigateur et proposez la modification au staff. GitHub peut créer automatiquement une copie personnelle du dépôt si vous n’avez pas de droit d’écriture.

Pour travailler avec aperçu et images, utilisez « Éditeur visuel local ». Il est servi par le wiki mais modifie uniquement le dossier de votre copie locale de ce dépôt, avec votre accord. Envoyez ensuite les fichiers avec GitHub Desktop et ouvrez une pull request. Aucun VS Code, npm, Cloudflare ou service OAuth n’est nécessaire pour contribuer. Voir [CONTRIBUTING.md](CONTRIBUTING.md).
